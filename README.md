# Product Inventory Manager

A simple browser-based Product Inventory Manager developed using
TypeScript, HTML, and CSS as part of the Advanced Web Technologies
(AWT) assignment for MCA.

## About the Project

The Product Inventory Manager helps users manage products and
monitor inventory details through a simple and user-friendly
web interface.

## Features

- Dashboard displaying inventory statistics
- Add new products
- View product details
- Search products by name
- Delete products
- Display available and out-of-stock status
- Calculate total inventory value
- Responsive user interface

## How to Run Locally

### Prerequisites

- Node.js
- npm
- Visual Studio Code

### Installation

1. Clone the repository:

   git clone https://github.com/YOUR_USERNAME/product-inventory-manager.git

2. Open the project folder:

   cd product-inventory-manager

3. Install TypeScript:

   npm install --save-dev typescript

4. Compile the TypeScript code:

   npx tsc

5. Open index.html in your browser.
